### 3. Helper Methods Added

**Location:** After `build_prompt_messages()` method (after line 494)

#### generate_context_id() (lines 496-519)
```php
private function generate_context_id( $context ) {
    $site_id  = get_option( 'siteurl' );
    $locale   = get_locale();
    $business = isset( $context['business_name'] ) ? $context['business_name'] : '';
    $industry = isset( $context['industry'] ) ? $context['industry'] : '';
    $seo_mode = isset( $context['seo_mode'] ) ? (int) $context['seo_mode'] : 0;

    $fingerprint = sha1( $site_id . '|' . $locale . '|' . $business . '|' . $industry . '|' . $seo_mode );
    return 'ctx_' . substr( $fingerprint, 0, 7 );
}
```

#### promptSafe() (lines 521-533)
Sanitizes values to prevent prompt injection:
- Strips HTML tags
- Normalizes whitespace
- Removes pipe delimiters and special characters
- Limits token count

#### csvSafe() (lines 535-556)
Converts arrays to safe CSV strings:
- Max 5 items
- Max 4 tokens per item
- Sanitized with promptSafe()

### Timeout/Scaling Risk Identified ⚠️ CRITICAL

**Problem:**
Current sequential processing architecture will timeout for large batch operations (500+ images).

**Performance Measured:**
- **37 images:** 4 min 3 sec (243 seconds)
- **Average:** 6.57 sec/image
- **Breakdown:** OpenAI API ~4-5s, network ~1s, DB ~0.5s, resize ~0.5s

**Scaling Projections:**

| Image Count | Time Required | Will Timeout? |
|-------------|---------------|---------------|
| 37 images | 4 min 3 sec | ✅ Works |
| 100 images | ~11 minutes | ⚠️ May timeout (browser) |
| 500 images | ~55 minutes | ❌ WILL timeout |
| 1000 images | ~110 minutes | ❌ WILL timeout |

**Timeout Layers:**
1. **PHP timeout** (default 30-60 sec) - will hit at ~10 images
2. **Browser timeout** (varies, ~2-5 min) - will hit at ~40 images
3. **Gateway timeout** (nginx/apache, ~60 sec) - will hit at ~10 images
4. **User experience** - no one will wait 2 hours staring at spinner

**Current Architecture Issue:**
```
Sequential blocking execution:
Image 1 → API call (5s) → Save → Image 2 → API call (5s) → Save → ...
```

**Solution Required:**
1. **Chunk-based UI processing** - Process 10-20 images per request with progress updates
2. **Concurrent API calls** - Process 5-8 images in parallel within each chunk
3. **Background job system** - For 500+ image batches, use WP-Cron with async processing

**Impact:**
- **Low:** Current 37-image test batch - ✅ Works fine
- **Medium:** 50-100 images - ⚠️ May timeout depending on server config
- **High:** 500+ images - ❌ Will definitely timeout

**Priority:** Medium (works for typical use cases, but won't scale for enterprise)

**Status:** Identified, solution designed, implementation pending

**Affected Image:** patient-testimonial-waterfront-structure.webp (ID 754)

**Symptom:**

**Root Cause:**

**Why 125?** Accessibility best practice - screen readers work better with concise ALT text. However, the implementation truncates mid-sentence, making it look broken.

**Proposed Solutions:**

**Option 1: Word-Boundary Truncation (Recommended)** ✅
```php
// In class-msh-metadata-validator.php
private function truncate_at_word_boundary( $text, $max_length = 125 ) {
    if ( mb_strlen( $text ) <= $max_length ) {
        return $text;
    }

    // Truncate at last complete word before limit
    $truncated = mb_substr( $text, 0, $max_length );
    $last_space = mb_strrpos( $truncated, ' ' );

    if ( $last_space !== false ) {
        $truncated = mb_substr( $truncated, 0, $last_space );
    }

    // Add ellipsis if truncated
    return rtrim( $truncated, '.,;:!?' ) . '…';
}
```

**Expected Result:**
```
ALT: "A red metal structure stands prominently on a wooden pier extending
over the water…"
```

**Option 2: Sentence-Boundary Truncation**
```php
private function truncate_at_sentence( $text, $max_length = 125 ) {
    if ( mb_strlen( $text ) <= $max_length ) {
        return $text;
    }

    // Try to end at a sentence boundary
    $truncated = mb_substr( $text, 0, $max_length );
    $last_period = mb_strrpos( $truncated, '. ' );

    if ( $last_period !== false && $last_period > 50 ) {
        // Use sentence boundary if it's not too short
        return mb_substr( $truncated, 0, $last_period + 1 );
    }

    // Fall back to word boundary
    return $this->truncate_at_word_boundary( $text, $max_length );
}
```

**Option 3: Flexible Limit (125-150 chars)**
- Allow up to 150 characters if needed to complete a sentence
- Hard stop at 150 regardless

**Option 4: AI-Enforced Limit**
- Strengthen prompt instruction to enforce 100-125 char limit
- Add post-generation validation that regenerates if over limit
- Fallback to truncation if AI repeatedly fails

**Recommendation:** Implement **Option 1** (word-boundary truncation) as it's:
- Simple to implement
- Maintains accessibility goal (keeps ALT text concise)
- Improves UX significantly (no more mid-word cuts)
- Clear indication of truncation (ellipsis)

**Impact:** Low priority - affects only ~3% of images that exceed 125 chars. Does not affect functionality, only presentation quality.

```php
private function truncate_at_sentence( $text, $max_length = 125 ) {
    if ( mb_strlen( $text ) <= $max_length ) {
        return $text;
    }

    $truncated = mb_substr( $text, 0, $max_length );

    // Find last sentence-ending punctuation (with space after to avoid abbreviations)
    $last_period   = mb_strrpos( $truncated, '. ' );
    $last_question = mb_strrpos( $truncated, '? ' );
    $last_exclaim  = mb_strrpos( $truncated, '! ' );

    $last_sentence = max(
        $last_period !== false ? $last_period : -1,
        $last_question !== false ? $last_question : -1,
        $last_exclaim !== false ? $last_exclaim : -1
    );

    // Use sentence boundary if it's not too short (40% threshold)
    if ( $last_sentence !== false && $last_sentence > 0 && $last_sentence > ( $max_length * 0.4 ) ) {
        return mb_substr( $truncated, 0, $last_sentence + 1 );
    }

    // Fallback: word boundary with ellipsis
    $last_space = mb_strrpos( $truncated, ' ' );
    if ( $last_space !== false ) {
        $truncated = mb_substr( $truncated, 0, $last_space );
    }
    return rtrim( $truncated, '.,;:!?' ) . '…';
}
```

**Key Features:**
- Finds last sentence ending (`. `, `? `, `! `) within character limit
- 40% threshold prevents overly short results (e.g., "Hello." when max is 125 chars)
- Detects space after punctuation to avoid abbreviations like "Dr." or "U.S.A."
- Falls back to word-boundary with ellipsis if no good sentence boundary found
